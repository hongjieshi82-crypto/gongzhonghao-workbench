# 横幅封面标题规范

【横幅封面一体化】封面是一张900×383（约2.35:1）的完整横幅，不再为1:1方图预留或居中任何安全区，也不读取coverCropOffset。标题和画面作为同一张图设计：标题文字层与场景共用光源、透视和动势方向，至少有一种连接方式让文字和画面咬合（面板或色带的边缘渐隐进场景、光轨/箭头/胶带从标题延伸到主体、主体的局部轻微压在面板边缘前、标题投影落在场景上）。禁止“左边一块纯色写字、右边一张图”的分栏拼接，也不要把标题放进与画风无关的通用圆角框。字体、填色、容器和装饰按本风格的横幅标题处理执行，并与绑定的公众号排版标题一致。完整文章标题逐字继承，按语义分成引入小字和主标题（重点词可单独成行或换色），长标题靠换行和字号层级解决，不删字；文字离横幅外边缘至少约32px，主标题在缩略到约300px宽时仍能读出。只检查横版成品，不再输出或验收中央方图。

参考做法：data/images/personal-agent/cover-v2-a.png（用户认可的玻璃面板横幅）——半透明面板 + 渐隐进场景的霓虹描边、光束把面板和角色连起来、小栏目标签、白色主标题 + 渐变重点行。

## 手写署名（所有风格）

**所有风格的每张正文图和封面右下角都必须有小号手写「@怂怂的AI脑内小剧场」**（离边缘约 3%，字号约图宽的 2.5–3%；浅色画面近黑 #1A1A1A、深色画面白色，背景杂时加柔和投影），逐字正确，不压住主体或标题；这是唯一的署名，不另加品牌、网址、水印或 © 标记。生成后逐字检查。

## 各风格的横幅标题处理（与绑定的公众号排版一致）

### dynamic-narrative-comic（dynamicNarrative）→ 排版：动感杂志
得意黑式斜体粗字 · 白字靛蓝描边 + 橙色硬偏移影 · 速度线 · 橙色光轨接入画面动势
- 字体：粗重斜体中文展示字（得意黑/站酷类斜体，或粗黑体整体右倾约6°）
- 填色：主标题白色，重点行橙黄渐变；引入小字淡蓝白
- 描边/投影：深靛蓝描边约字高6%，外加橙色实色硬偏移投影（右下约字高8%），与排版标题 text-shadow 同款
- 容器：不用框；标题下方三段递减的橙色速度条（长-中-点），上方小字“▶▶▶”栏目标
- 光效/连接：一条橙色光轨从标题下沿起笔，顺着画面主要动势斜向上扫进主体或其光源；少量白色星芒
- 层次：标题整体沿画面斜线排布，主角色的动作方向指向标题或从标题冲出

Prompt 段落：【横幅标题·动感叙事漫画】标题用粗重斜体中文展示字，整体沿画面斜向动势右倾；主标题白色、重点行橙黄渐变，统一深靛蓝描边并带橙色实色硬偏移投影（对应排版“动感杂志”的标题投影）。标题下方三段递减橙色速度条，可加“▶▶▶”小栏目标。一条橙色光轨从标题下沿起笔扫进主角色或其光源，主角色动作方向与标题呼应，形成同一场景里的冲击感；蓝紫夜空在标题背后自然压暗以保证对比，不画独立底框。

- 填色：主标题白色，重点行酸橙荧光绿渐变并带轻微辉光；引入小字浅灰
- 描边/投影：无描边，靠暗色面板与轻投影取得对比
- 容器：半透明石墨磨砂玻璃 HUD 面板，小圆角（约8px），左上角与左边是一条荧光绿边光折线，面板向主体方向渐隐；面板内左上为深色小标签“● 栏目名”（荧光绿等宽字），标题下方6段进度条（已读段为绿）
- 光效/连接：面板底边的荧光绿边光延伸成细光线，沿画面中的金属边缘或结构线进入主体
- 层次：面板压在工业金属场景的前景虚化区域上，主体金属件的一角可略微伸到面板边缘前

Prompt 段落：【横幅标题·黑金属荧光科技】标题放在半透明石墨磨砂玻璃HUD面板里，面板小圆角、向主体方向渐隐进场景，不是实心黑块；面板左上与左边一条荧光绿边光折线，底边的绿光继续延伸成细光线，沿金属边缘或结构线连到主体。主标题粗重黑体白字，重点行荧光绿渐变带轻辉光；面板内左上可放等宽字小标签与6段进度条（对应排版“金属报告”的 SEC 进度条编号）。主体金属件可以一角压在面板边缘之前，体现同一空间。
