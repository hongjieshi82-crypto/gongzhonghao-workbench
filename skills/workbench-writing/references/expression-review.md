# 表达审稿

初稿完成或用户要求润色时读取。检查实际问题，不能看到某个词就判定需要删除。

1. **论断落地**：把“重大突破”等评价与具体变化对照，无证据的影响判断删除或收窄。
2. **来源明确**：核对“专家认为、研究显示”是否对应已读来源；补不出来源时不能编一个。
3. **逻辑有效**：检查每个转折、对比与外推是否增加信息，删掉只制造气势的排比与虚假跨度。
4. **术语稳定**：同一对象保持名称一致，避免为换词造成概念混乱；简单关系直接说清楚。
5. **节奏自然**：取消机械三点列举、过量加粗和装饰性符号；真正需要的列表、引用、标点保留。
6. **正文干净**：去掉聊天应答、服务承诺和模板结尾；必要的事实时效、风险边界不能删。
7. **改动可追溯**：润色前后核对数字、主体、因果、引用和不确定程度，不添加未经核实的细节。

不得把每个三项列表改成两项，或用虚构情绪制造个性。成稿需要的是准确、顺畅、符合作者声音；不是模仿某人的习惯或通过检测器。
